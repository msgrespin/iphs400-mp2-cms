# CMS field notes — WordPress Playground

1. I noticed that you can pull plugins from the internet to customize the site.
2. The website is not connected to the internet but I can still fully edit and customize it remotely without having to have it published to the public. By this I mean I can see my saved drafts remotely before I publish them, after I publish them the public is able to see my finished product.
3. Templates are easy to find on the WordPress playground site but they are less creative.
4. I noticed that I can see different views of the website depending on who I am logged ( Visitors, editors, and admins) in as in that moment of time.
5. When I am an editor the User tab disappeared. Also, when I am an editor I get a "no permission" message when going to the Users address directly.
6. I learned another way to add plugin to the playground is via the URL slug.
